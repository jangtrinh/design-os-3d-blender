These supplement the existing loop; API knowledge remains in `knowledge/`. Read [workflow](../../../../docs/blender-ai-workflow.md) for intent and [recipes](recipes.md) for task routing. `MANUAL` means controller discipline, not an implemented hook or gate. Early-table times are UTC on 2026-09-05; later incidents carry their explicit source/time. Detailed session evidence is retained in the source workspace and is not included here.
