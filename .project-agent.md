# Project Agent — Blender AI Orchestration

## Identity
- **Product:** Blender AI Orchestration Foundation
- **Goal:** AI điều khiển Blender để dựng 3D, animation, render — qua MCP (interactive) + headless CLI (batch).
- **Owner:** Jang

## Tech Stack (binding)
- Blender 5.2.0 LTS local (`/Applications/Blender.app/Contents/MacOS/Blender`) — khớp target của `knowledge/` KB. Upgrade từ 4.3.2 ngày 260728, regression pass.
- MCP: `blender` server = ahujasid/blender-mcp tại `/Users/jang/blender-mcp` (socket addon port 9876)
- Headless: `blender -b` + scripts trong `scripts/` (Cycles; chọn CPU/Metal bằng profile đã kiểm tra cho scene, không mặc định GPU nhanh hơn; không dựa vào EEVEE cho đường batch macOS hiện tại)
- Asset construction: Blender-native data API, bmesh, modifiers, sculpt, and local project scripts only.
- No new generated/retrieved vendor mesh, paid credit, hosted-model call, or external asset download may enter production.
- Exception: an already-local artifact may be salvaged as a frozen scaffold when the user explicitly selects it; rebuild must be self-contained, provenance-recorded, repaired in Blender, and make zero further service calls.
- Local retopology gate: user-selected QRemeshify 1.1.0 may process a frozen scaffold offline through `scripts/run-qremeshify.py`; binaries are hash-pinned, GPL-3.0-or-later, and must pass macOS quarantine approval plus topology/visual gates before entering a build.

## Binding Rules
1. **bpy code: ưu tiên data API, tránh `bpy.ops`** trừ khi bắt buộc. Chi tiết: `knowledge/00-foundations/bpy-scripting-core.md`. Skill hiện hành: `blender-agent-core`, `blender-image-to-3d`, `blender-knowledge-workbench` — không có skill nào khác.
2. **Mọi pass phải kết thúc bằng verify theo ladder rẻ → đắt**: assert số (postcondition trong `AGENT_OK`) trước; ảnh (`preview_render(engine="EEVEE")`, viewport screenshot, turntable) chỉ cho điều mắt mới đánh giá được, và phải ghi kỳ vọng trước khi nhìn. Bước cuối của build luôn có verify visual. Part sẽ in/chế tạo: `scripts/production-gate.py` exit 0 với `spec.json` của build trước khi giao.
3. **Socket names/API** — introspect runtime và dùng `knowledge/20-shading/materials-pbr.md`; không dựa vào tên của phiên bản khác.
4. **MCP addon phải Connect trước** (Blender sidebar `N` → BlenderMCP → Connect to Claude) — nếu tool lỗi connection, báo user mở addon, đừng retry mù.
5. **Contract trước chi tiết**: part production phải có `builds/<slug>/spec.json` (schema `specs/build-spec.schema.json`) trước khi dựng chi tiết; thiếu kích thước/payload/duty → `request-input`.
6. **Quyết định thành công bằng sentinel** `AGENT_OK`/`AGENT_FAIL` (dòng cuối stdout), không bằng exit code Blender hay chữ "executed successfully".
7. Assets tải về → `assets/`, render output → `output/` (cả 2 gitignored nếu có repo).

## Layout
- `AGENTS.md` — file vận hành chính (loop, execution contract, verify ladder, failure map); `CLAUDE.md` import nó
- `.agents/skills/` — routers `blender-agent-core`, `blender-image-to-3d` (native reference reconstruction), và `blender-knowledge-workbench` (cross-corpus reading packs); `.claude/skills/` giữ mirror cho Claude. Core routing/reference là nguồn hiện hành ở `.agents/` và phải đồng bộ mirror khi đổi.
- `knowledge/` — domain files được kiểm kê trong catalog hiện hành, router `INDEX.md` — kiến thức chuyên sâu; skills trỏ vào
- `scripts/` — `agent_runtime.py` (sentinel contract), `headless-run.sh`, `production-gate.py` + `production_gate/` (gate in 3D/kích thước/chuẩn), `agent-verify-lib.py` (sense organs), turntable, comparison-sheet
- `specs/` — schema + ví dụ build spec (contract kiểm được)
- `builds/` — build script idempotent + .blend theo từng object
- `docs/system-architecture.md` — kiến trúc đầy đủ
- `docs/blender-ai-workflow.md` — workflow hiện hành, skill/recipe routing và các giới hạn bằng chứng
- `docs/blender-workflow-improvement-backlog.md` — sửa lỗi executable chưa triển khai; không nhầm quy tắc MANUAL với gate đã enforce
- `plans/reports/` — research + build reports
