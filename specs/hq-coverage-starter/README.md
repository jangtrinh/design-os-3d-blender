# Incomplete coverage starter

Copy this folder beside a new candidate. These files deliberately fail: no source, camera, actual hashes or review evidence has been invented. The empty settings object and empty object list are deliberately invalid even if the other fields are filled. Fill the source-specific feature inventory and shot plan after reference/form review, then replace UNSET pins with actual SHA-256 values. Relative paths resolve from coverage.json. Add actual reviews only after inspecting native-density proof images.

See [the complete workflow](../../docs/hq-coverage-gate.md) for review fields, proof regions, guarded launch, and evidence limits. Never change an unset or pending field to PASS merely to satisfy the checker.
