# From reference image to reviewable component

The ORC showcase media is a visual record of native Blender reconstruction. Its source scenes, internal plans, and reference images are not part of this repository. This note explains the review discipline that made the output assessable without presenting it as an engineering package.

The primary 3/4 reference establishes what an observer can actually count, where major assemblies sit, their facing, and the silhouette. Close images refine local construction. When a question becomes mechanical—routing, an instrument station, a tap, or a connection—the workflow first consults applicable drawings or official technical documents. An analogue CAD source can explain a profile family, but it cannot identify the depicted unit, set dimensions, or qualify a selected design.

Work begins with the visual identity risk: a controller makes the first native prototype for a new family, then captures its axes, mount ports, parameter range, and falsifiers. Reuse is earned by a second real consumer and a regression proof. This avoided treating a plausible instrument body as proof that it had a valid host, adapter, or service orientation.

Final review uses named features and named proof shots. A close industrial enclosure is read as construction—door return, hinges, lock, HMI recess, controls, ventilation, and service detail—rather than as a clean box with the right object count. Bores, coplanar joins, fastener families, labels, and highlights are inspected at the target pixel density. Numeric topology and package checks remain useful, but they do not decide visual fidelity.

Each reviewable output binds its candidate, settings, proof images, and final images to immutable hashes. If source, camera, or resolution changes, affected proof is renewed and prior media remains identified as evidence for the earlier revision. The optional HQ coverage command checks declared receipts only when the render uses its guarded launch route; direct rendering remains possible and is reported as such.

See [ORC component reconstruction lessons](../orc-session-lessons.md) for the reusable checklist and [the Separator worked example](../orc-separator-worked-example.md) for a bounded interface-repair sequence. The showcase is render-only documentation; it makes no claim about vendor identity, dimensions, pressure, fit, load, or manufacture.
